# Uživatelská dokumentace

Program se spustí příkazem: `python LINEAR_EQUATIONS.py`

Vstup užívateľa je výhradne konzolový, po spustení programu užívateľ zadáva počet rovníc, je to celé čislo vrátane nuly; pri nule program končí.
Následne postupne zadáva rovnice v tvare napr. `-x +   40z -   6  x +0g =  -54`
**Premenné sú označované jedným písmenom.**
Pri vstupe na príklade môžeme vidieť, že užívateľ môže zadať 1x / -1x ako x / -x;
číslo +(-140x) je zadávané priamo ako -140x; 
počet medzier medzi každým znakom môže byť akýkoľvek a hodnota 0g musí byť explicitne napísana.
