# Uživatelská dokumentace

Program se spustí příkazem: `python LINEAR_EQUATIONS.py`
## Vstup
Vstup užívateľa je výhradne konzolový, **po spustení programu užívateľ zadáva počet rovníc**, je to celé čislo vrátane nuly; pri nule program končí. V prípade čisla z intervalu celých čisel bez nuly program pýta rovnice, t.ž. **jedna rovnica je jeden vstup**.
## Tvar vstupu rovnice
* Rovnica sa zadáva v tvare napr. `-x +   40z -   6  x +0g =  -54`
*  **Premenné sú označované jedným písmenom**
* Užívateľ môže zadať 1x / -1x ako x / -x
* Číslo +(-140x) je zadávané priamo ako -140x
* Počet medzier medzi každým znakom môže byť akýkoľvek 
* Pokiaľ sa premenná v rovnici nenachádza no v nejakej inej áno, užívateľ ju písať nemusí, ak ju nenpaíše, chápe sa, že jej koeficient je nulový
