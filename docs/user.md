# Uživatelská dokumentace

Program se spustí příkazem: `python LINEAR_EQUATIONS.py`
#Vstup
Vstup užívateľa je výhradne konzolový, po spustení programu užívateľ zadáva počet rovníc, je to celé čislo vrátane nuly; pri nule program končí. V prípade čisla z intervali celých čśiel bez nuly program pýta rovnice.
#Tvar vstupu rovnice
* Rovnica sa zadáva v tvare napr. `-x +   40z -   6  x +0g =  -54`
*  **Premenné sú označované jedným písmenom.**
* užívateľ môže zadať 1x / -1x ako x / -x
* číslo +(-140x) je zadávané priamo ako -140x
* počet medzier medzi každým znakom môže byť akýkoľvek 
* hodnota 0g musí byť explicitne napísana
